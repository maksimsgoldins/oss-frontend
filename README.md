# OSS Frontend Render Starter

## Local
npm install
copy .env.example .env
npm run dev

## Render Static Site
Build Command:
npm install && npm run build

Publish Directory:
dist

Environment variable:
VITE_API_BASE=https://YOUR-BACKEND.onrender.com/api

Important:
Enable CORS on backend for:
- your Render frontend URL
- http://localhost:5173
